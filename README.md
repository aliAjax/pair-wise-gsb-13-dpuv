# 卸油验收台 · 罐车到站交接

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

按仓登记罐车卸油交接，解决“只记总升数、司机与站长对不齐每仓交付”的问题。

## 业务规则

- 录入：车牌、交接单号、卸油日期、司机、站长，以及每仓的仓号、交接单铅封号、现场铅封号、交接温度、罐车表读数、站内表读数。
- 折算：以 **20℃** 为基准，每偏差 1℃ 对交付量（罐车表）修正 **0.12%**：
  `折算升数 = 罐车表 × (1 - (交接温度 - 20) × 0.12%)`，站内表读数为实收量。
- 停待复核（命中任一条，批次先停、不入账）：
  - 现场铅封与交接单铅封不一致；
  - 交接温度与 20℃ 偏差超过 **3℃**；
  - 20℃ 折算后短溢率绝对值超过 **0.5%**。
- 停待批次必须由复核人填写 **复核人、责任认定、处置意见** 后才能入账。
- 已复核（入账）批次冻结，不能直接覆盖；改单必须填写原因，另存为新版本，旧版本冻结保留、可随时查看旧值。
- 重开页面后数据仍在（localStorage），可按车牌和日期（含状态）查询。

## 分层结构

- `src/domain/types.ts`：数据模型。
- `src/domain/calc.ts`：纯计算（温度折算、短溢、停待判定），不依赖 DOM/存储。
- `src/data/unloadRepository.ts`：批次组装、状态流转、改单版本与 localStorage 持久化。
- `src/stores/unload.ts`：状态编排（查询、指标、保存/复核/改单）。
- `src/components/`：`UnloadForm`（录入/改单）、`BatchCard`（批次与版本）、`CompartmentTable`（分仓明细）、`ReviewDialog`（复核入账）。
- `src/App.vue`：页面组装。
