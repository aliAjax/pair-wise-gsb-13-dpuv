# 罐车卸油验收台

- 行业：石油（加油站到站卸油交接）
- 技术栈：Vue3、Vite、TypeScript、Pinia
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 业务规则

罐车到站按仓验收，逐仓录入**车牌、铅封号（交接单/现场）、仓号、交接温度、罐车表读数、站内表读数**：

1. **体积折算**：以 20℃ 为基准，每差 1℃ 按交付量修正 0.12%
   `修正系数 = 1 −（交接温度 − 20）× 0.12%`，罐车表与站内表均折算到 20℃ 后比对短溢。
2. **挂起红线**（任一仓命中则整批「先停待复核」）：
   - 现场铅封与交接单铅封号不一致；
   - 交接温差超过 3℃；
   - 折算后短溢率超过 ±0.5%。
3. **复核入账**：挂起批次须由复核人填明**责任归属与处置意见**后才能入账；全部正常的批次自动入账。
4. **冻结与改单**：已复核批次冻结，不可直接修改/删除；改单须填写原因，系统另建版本（V1/V2…），
   旧版本全部旧值原样保留，可在批次卡片中切换查看。待复核批次可直接修正并重新校验，或删除。
5. **查询**：数据持久化在浏览器 localStorage，重开页面可按车牌（模糊）、交接日期、状态查询。

## 分层结构

| 层 | 文件 | 职责 |
| --- | --- | --- |
| 数据模型 | `src/types.ts` | 批次、版本、仓、复核、改单留痕类型 |
| 计算 | `src/lib/calc.ts` | 温度系数、20℃ 折算、短溢率、挂起判定（纯函数） |
| 保存 | `src/lib/storage.ts` | localStorage 读写、种子数据 |
| 数据状态 | `src/stores/batches.ts` | Pinia store：建批、修正、复核、改单、冻结保护 |
| 页面 | `src/App.vue`、`src/components/*` | 录入表单、批次卡片、查询与指标编排 |
| 展示格式 | `src/lib/format.ts` | 体积/短溢/系数/日期格式化 |
